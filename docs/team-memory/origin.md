# Origin

This repo was created from the **agentic-app-starter** GitHub template.

The template bundles a reusable agent workflow (superpowers brainstorm→plan→execute, project
skills, GitHub-issue-first gate, shared team memory) on top of a working stack: React 18 + TS
(strict) + Vite + Vitest, Supabase (Postgres + Row Level Security, anon-key browser client), and
Cloudflare Workers deploy. It ships an example `items` CRUD feature demonstrating the
data → hooks → screen pattern; replace it with the real product.
